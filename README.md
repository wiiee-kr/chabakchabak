# 차박차박 · 수길따라 MVP

차박차박의 공식 로고와 심볼은 사용자가 2026-11-17 제공한 PNG를 사용합니다. 새 화면과 수정 작업은 [브랜드 자산 기준](prototype/assets/BRAND.md)을 따릅니다.

크리에이터 콘텐츠를 기반으로 한 시연용 MVP 프로젝트입니다. 차박차박을 우선 진행하고, 공통 화면 구조를 수길따라에 재사용합니다.

## 브랜치

- `main`: 통합·검증된 시연 버전
- `design/prototype`: HTML/CSS 디자인 프로토타입과 FE 전달 자료
- `feat/*`: 개발자가 작업 단위로 생성하는 구현 브랜치

## 작업 영역

- `prototype/`: 디자인 프로토타입. `design/prototype` 브랜치에서 작업합니다.
- React 및 서버 작업 경로는 개발자와 협의 후 확정합니다.

디자인은 안정된 화면 단위로 전달하며, React 구현·앱 패키징·TestFlight는 FE가 담당합니다.

## 차박차박 닉네임 정책

- 익명·랜덤 닉네임 시스템 없이 모두 공개 닉네임으로 활동합니다.
- 닉네임은 사용자 간 중복될 수 없으며, 글·댓글·대댓글에서 같은 닉네임을 사용합니다.
- 대댓글 작성자를 구별하려고 닉네임 뒤에 숫자를 자동으로 붙이지 않습니다.
- 현재 프로토타입은 브라우저 내 예시 사용자와 저장된 데이터 기준으로 중복을 검사합니다. 실제 서비스에서는 서버에서 전체 계정의 닉네임 유일성을 보장해야 합니다.

- 프로필 썸네일은 사용자별로 다르게 표시하며, 같은 닉네임은 글·댓글·대댓글에서 동일한 썸네일을 사용합니다.
- 썸네일은 이니셜이나 일러스트가 아닌 실제 사진을 사용합니다.

## 공통 화면 간격

섹션 타이틀 로우의 하단과 첫 콘텐츠 사이의 간격은 12px입니다. 공통 토큰은 `--section-content-gap`입니다.

앱바 하단에서 본문의 첫 요소까지의 간격은 모든 활성 페이지에서 20px로 통일합니다. 공통 값은 `prototype/styles/layout.css`에서 관리합니다.

## 전역 타이포그래피 규칙

세그먼트 탭의 레이블은 선택·미선택 상태 모두 미디움(500)을 사용합니다.

앱 전체에서 글자 굵기는 최대 600(세미볼드)까지만 사용합니다. 700 볼드 및 그 이상의 굵기는 사용하지 않습니다. 제목, 본문, 닉네임, CTA, 내비게이션, 기본 강조 태그에도 동일하게 적용합니다.

- 앱바의 좌우 그룹을 감싸는 전체 로우는 투명 배경으로 유지한다. 흰색 배경은 개별 플로팅 그룹에만 적용한다.

- 토스트는 하단이 아닌 앱바와 같은 상단 위치에 표시하며, 앱바 위 레이어로 노출한다. 상단 안전영역을 반영한다.

- 모든 앱바 타이틀은 마이탭 기준으로 통일: 공통 앱 폰트, 18px / 500 / 행간 24px, 기본 자간, #191919.
