# 차박차박 공식 로고와 심볼

2026-11-17 사용자가 마지막으로 제공한 이미지 4종으로 교체한 최종 디자인입니다. 가로 BI 360 × 80, 세로 BI 798 × 648, 워드마크 474 × 132, 심볼 688 × 380 원본을 그대로 사용합니다.

- `chabak-logo.png`: 차박차박 워드마크. 원본 474 × 132, 투명 PNG.
- `chabak-symbol.png`: 파란 산과 민트색 산이 겹치는 심볼. 원본 688 × 380, 투명 PNG.

- `chabak-bi-horizontal.png`: 공식 가로 BI 세트. 원본 360 × 80, 투명 PNG. 홈 앱바 왼쪽에 사용합니다.
- `chabak-bi-vertical.png`: 공식 세로 BI 세트. 사용자가 다시 제공한 고해상도 원본 798 × 648, 투명 PNG. 흰색 스플래시 화면에 가로 240px로 표시합니다.

앱바와 스플래시에서는 개별 심볼·워드마크를 따로 조합하지 않고 사용자가 제공한 BI 세트를 그대로 사용합니다. 개별 파일은 단독 표시가 필요한 경우에만 사용합니다.
원본 색상, 투명도, 비율과 여백을 유지하고 CSS 필터로 재색칠하거나 늘려 변형하지 않습니다. 기본 배경은 흰색입니다.
기존 `chabak-symbol.svg`는 과거 임시 시안이며 새 화면에서 사용하지 않습니다. 대화에서 생성했던 산길 심볼도 이 최종 디자인을 대체하지 않습니다.
이 자산 지정 자체가 앱 전체 UI 색상 토큰의 변경을 의미하지는 않습니다.

## 슬로건 — 미확정

스플래시의 “오늘의 걸음이 내일의 풍경으로”는 시연용 임시 문구입니다. 공식 슬로건으로 취급하거나 확정된 브랜드 문구로 재사용하지 않습니다. 클라이언트 대면 미팅에서 슬로건 사용 여부와 최종 문구를 확인한 뒤 반영합니다. 그때까지 현재 시연 화면에는 임시 문구를 유지합니다.
