# 디자인 프로토타입

차박차박·수길따라의 HTML/CSS 프로토타입과 FE 전달 자료를 관리합니다.

- 작업 브랜치: `design/prototype`
- 앱 공통 폰트: Wanted Sans (`styles/fonts.css`, 로컬 폰트 파일 사용)
- 기본 기술: 시맨틱 HTML, 재사용 CSS, 필요한 최소 Vanilla JS
- 차박차박을 우선 구현하고 공통 화면을 재사용합니다.
- 검증되지 않은 콘텐츠는 `예시` 또는 `확인 예정`으로 표시합니다.
- React 구현 및 앱 빌드 코드는 이 경로에서 작성하지 않습니다.

## 디자인 시스템 원본

- [차박차박·수길따라 디자인 시스템](https://www.figma.com/design/kyRVfsumtaWbm4e96wrJB0?node-id=4-37)을 UI 작업의 기준으로 사용합니다. 기존 CSS 값을 디자인 시스템 규격으로 간주하지 않습니다.
- 수정할 컴포넌트의 Figma 원본과 토큰을 먼저 확인하고, 확인된 값은 `styles/design-system.css`에서 관리합니다. 사용자 지정 변경사항을 우선합니다.
- 화면을 만들거나 수정할 때는 용도와 위계에 맞는 기존 컴포넌트와 상태를 재사용합니다. 타이포그래피는 크기·굵기·줄높이·자간을 하나의 스타일로 적용하고, 색상·간격·모서리 반경은 해당 역할의 토큰을 참조합니다.
- 완료 전에는 실제 화면의 계산된 스타일을 원본 규격 또는 사용자 지정값과 대조합니다. 사용자가 별도로 정한 규격은 공통 디자인 규칙에 기록합니다.
- 버튼 문서: `4:906`. S: 높이 32 / 라디우스 8, M: 높이 40 / 라디우스 10, L: 높이 48 / 라디우스 12.
- 프로필 수정 버튼: `Button/Outlined/Tertiary`, M, Default (`4:816`), 가로 Fill. 좌우 패딩 16, 글자 Wanted Sans 14/500/20, 테두리 1px #d9d9d9, 글자 #262626, 채움 없음.
- Tertiary는 컴포넌트 설명과 개별 사용 규칙에 따라 Default·Disabled만 사용하며 Hover·Pressed를 임의로 추가하지 않습니다.

## 공통 디자인 규칙

- 산·코스 상세의 섹션 제목에는 Figma `Typography/Title/L`을 사용합니다. Wanted Sans SemiBold, 18px, 줄높이 28px, 자간 0입니다.
- 섹션 타이틀로 시작하는 콘텐츠 영역 앞에만 `var(--section-gap)`(40px)을 적용합니다. 예를 들어 산 상세의 ‘차박차박이 다녀온 영상’과 ‘코스’ 사이가 이에 해당합니다. 준비물 체크리스트의 그룹 박스 사이는 12px입니다.

- 앱바에 아이콘 버튼 하나만 있는 영역은 가로·세로 48px로 통일합니다.
- 다이얼로그·얼럿·액션 시트의 CTA는 권장 행동에 프라이머리 솔리드, 취소·삭제 등 신중한 선택에 tertiary stroke를 사용합니다. 버튼 2개는 가로, 3개 이상은 권장 행동을 위로 정렬해 세로 배치합니다. 파괴적 확인에서는 안전한 취소를 권장합니다.

- 보톰시트는 타이틀–본문 12px, 본문–하단 CTA 20px 간격을 적용합니다.

- 롱버튼 CTA의 레이블 크기는 유지하고, 일반 CTA만 한 단계 작게 적용합니다(16→14px, 18→16px).

- CTA 레이블 크기는 기존보다 한 단계 키웁니다: 14·15px→16px, 16·17px→18px. 버튼 높이와 메뉴 레이블 크기는 유지합니다.

- 시트·다이얼로그의 본문 글자는 기존보다 한 단계 크게 적용합니다: 마이·설정 12→14px, 커뮤니티 시트 14→16px, 준비물 다이얼로그 17→18px.

- 메뉴 로우와 내부 아이콘에는 프레스드 배경·네이티브 탭 하이라이트를 표시하지 않습니다.

- 2뎁스 리스트형 레이블의 글자 크기는 마이 메뉴와 같은 공통 토큰 `--menu-label-font-size`(15px)을 사용합니다. 알림 토글·내 계정 정보 행·차단 사용자 이름에도 적용합니다.

- 2뎁스 이상 화면의 메뉴 리스트는 항목 사이 세로 간격을 8px, 각 항목의 위·아래 패딩을 각각 8px로 적용합니다(알림 설정 포함).

- 마이 메뉴와 알림 설정 항목의 레이블 굵기는 Regular(400)를 사용합니다.

- 보톰 내비게이션 활성 탭의 레이블·아이콘은 프리미티브 블루의 가장 어두운 `Blue/900` (`#1B326B`)을 사용합니다.

- 일반 라인 아이콘의 기본 선 두께는 **1.5px**입니다. Figma 원본 SVG를 가져올 때도 `stroke-width="1.5"`로 맞춥니다. 솔리드 아이콘·브랜드 로고·일러스트에는 적용하지 않으며, 별도 지정이 있을 때만 예외로 합니다.

- 마이 화면의 메뉴 섹션 디바이더는 커뮤니티 목록과 같은 1px 두께, `#f6f6f6` 색상을 사용합니다.

- 별도 일러스트를 지정한 화면을 제외한 빈 데이터 화면에는 차박차박 심볼 형태의 낮은 볼륨·흑백 3D 일러스트(`assets/chabak-symbol-empty-3d.png`)를 사용합니다. 지정된 커뮤니티·댓글·네트워크 오류 일러스트는 유지합니다.

- 메뉴 로우에는 쉐브론(오른쪽 방향 화살표)을 사용하지 않습니다.

- 섹션·메뉴 영역 위의 보조 분류 문구(아이브로우)는 표시하지 않습니다. 메뉴명과 기능상 필요한 제목은 유지합니다.

- 빈 화면 상태의 안내 텍스트에는 마침표(`.`)를 붙이지 않습니다.

- 앱바 캡슐 하단부터 본문의 첫 요소까지 간격은 **16px**입니다. 탭·화면별 액션에도 같은 간격을 적용합니다. 단, 빈 화면·오류 화면의 아이콘은 앱바 또는 상위 요소 하단에서 **56px** 떨어뜨립니다(내 활동·댓글 빈 상태 포함).

- 앱바는 좌우로 분리된 두 개의 플로팅 캡슐입니다. 각 캡슐에 보톰 내비바와 같은 흰색 배경을 적용하고 가운데는 투명하게 비웁니다. 앱바 그림자는 보톰 내비바보다 옅고 좁게 적용합니다(사방으로 균일한 그림자: X/Y 0px, blur 8px, 검정 8%). 좌우 여백 16px, 상단 여백 12px + 안전 영역을 적용합니다.
- 왼쪽은 뒤로가기 + 화면 타이틀, 오른쪽은 알림센터 + 검색 순서입니다. 등록·더보기 같은 화면별 액션은 앱바 아래에 둡니다.

- 모든 화면의 앱바 높이는 **48px**로 통일합니다. 상단 상태 표시줄·노치 안전 영역은 앱바 바깥 여백에 더합니다.
- 공통 높이는 `styles/layout.css`의 `--app-bar-height`에서 관리합니다.

## 화면

- `/`: 기존 스플래시
- `/home.html`: 로고 자리와 사진 썸네일 MY 버튼을 배치한 홈 (본문 비움, MY → 마이페이지)
- `/mypage.html`: 프로필과 닉네임 수정, 내 활동·준비물·차단 관리 바로가기. 닉네임은 `chabak-profile-v1`에 저장되며 커뮤니티 글·댓글에도 같은 공개 닉네임을 표시합니다.
- `/community.html`: 최신 요니버스 앱 UI 기반 커뮤니티 프로토타입

## 실행

저장소 루트에서 `python3 scripts/preview.py` 실행 후
`http://localhost:5500/community.html`을 엽니다.

## 커뮤니티 구현 범위

`community.html`은 현재 요니버스 앱 코드를 기준으로 옮긴 HTML UI를 사용합니다. 재사용 소스는 `community-ui/`이며 상세 사용법은 [커뮤니티 UI](community-ui/README.md)를 참고하세요.

- 두 줄 카테고리, 목록, 글쓰기·상세, 투표 작성·참여·결과
- 댓글·대댓글·좋아요, 더 보기·접기, 공개 닉네임, 임시 글 저장
- 검색, 내 활동, 숨기기·신고·차단 시연
- 강조색은 `community-ui/theme.css`에서 변경

브라우저 저장 키는 `chabak-community-latest-v2`입니다. 기존 `chabak-community-v1`의 데이터는 첫 진입 시 복사해서 읽으며 원본은 보존합니다. 실제 서비스 API는 연결하지 않습니다. 이전 사진은 읽어오지만 최신 요니버스 UI에는 사진 첨부 버튼이 없어 새 글 사진 첨부는 제공하지 않습니다.

기존 `styles/community.css`, `scripts/community.js`와 이전 HTML 복사본 `yoniverse-community/`는 보존하며, 현재 진입점에서는 사용하지 않습니다.

## 준비물 와이어프레임

`http://localhost:5500/packing.html`에서 실행합니다.

- 준비물 홈, 기본 준비물 편집, 새 체크리스트, 저장된 체크리스트
- 카테고리 전체/일부 선택, 항목·카테고리 추가/수정/삭제
- 항목 이동 메뉴와 드래그앤드랍, 길게 누르기와 메뉴 버튼
- 기본 목록은 이후 생성 목록에만 반영, 저장된 목록에서 선택적으로 기본 목록에 추가
- 산행 목록 복사 및 챙김 체크 초기화, 홈·상세 진행률
- 브라우저 저장소 `chabak-packing-wf-v1` 사용. 서버나 기기간 동기화는 없습니다.

## 아이콘 스타일 기준

- 사용자 지정 참고: [Untitled UI Icons — Line icons](https://www.figma.com/design/vgzafDvxKV1bnebBFVWi9a?node-id=181-128951).
- 기본 UI 아이콘은 해당 라이브러리의 간결한 윤곽, 둥근 선 끝과 모서리, 일관된 시각적 두께를 참고합니다. 확인한 `message-chat-circle`의 기본 크기는 24px입니다.
- 아이콘을 추가·교체할 때 해당 Figma 원본을 확인하고 화면의 지정 크기에 맞춥니다.
- 하단 내비게이션은 사용자 지정 솔리드 스타일과 두 봉우리·아치형 문 홈 아이콘을 유지합니다.
- 색상은 차박차박 디자인 시스템 토큰을 사용합니다.

## 엣지케이스 화면

- `/community.html#/network-error`: 네트워크 오류 시안. 재시도는 브라우저 연결 상태를 확인하고 온라인이면 커뮤니티로 이동합니다. 실제 API 재요청은 서비스 연동 시 구현합니다.
- `/community.html#/notifications`: 알림센터 빈 화면.
- 앱바 아래 56px, 아이콘 아래 20px. 네트워크 제목과 설명 사이 12px, 설명과 tertiary stroke 롱버튼 사이 20px.

- `/community.html#/community-empty`: 커뮤니티 빈 화면 미리보기(저장된 글 유지). 실제 목록에 표시할 글이 없을 때도 동일하게 표시합니다. 앱바 아래 56px, 아이콘 아래 20px, 제목과 설명 사이 12px. 글쓰기 버튼과 하단 내비게이션 유지.
